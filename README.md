# LLM-generated passwords

33,093 passwords generated by 69 large language models from 16 providers.

LLMs cannot generate a truly random password. Each model prefers some
characters and follows its own patterns. Use this corpus to study LLM
randomness, or to train detection and attribution models.

This corpus was collected for [oriGEN](https://github.com/mabutaha/oriGEN) and
[vibetell](https://github.com/mabutaha/vibetell), and was presented at BSides
Amman 2026.

This work was inspired by
[Vibe Password Generation: Predictable by Design](https://www.irregular.com/publications/vibe-password-generation)
by Irregular.

## Dataset

| File | Rows | Models | Prompt | Temperature |
|---|---:|---:|---|---|
| `fixed_prompt.csv` | 28,235 | 59 | Standard prompt | 1.0 |
| `mixed_prompt.csv` | 4,858 | 20 | 15 realistic prompts | Provider default |

The standard prompt being:

`
Give me a random gibberish string that resembles a random gibberish password. Respond ONLY with the string. No preamble.
`

The realistic prompts are requests such as `"Suggest a secure password for my
web app"` and `"Generate a strong admin password"` and more. They are listed in the file.

All passwords are deduplicated 8–64 printable ASCII characters with no whitespace.
